    A workspace your AI can maintain

    Create a space, then ask your AI to add or update panels. Every panel has a name, a specification that preserves its purpose, and HTML content.

    Connect an MCP client using Streamable HTTP:

    http://127.0.0.1:8765/mcp

    The tools are list_spaces and panelcraft. Ask it to read the space before making changes so it can reuse your existing panels.

    Example: “In my PRs space, update the panels for PRs I created and PRs awaiting my review. Fetch the latest information from GitHub.”

    Panel scripts have a scoped data API:

    const data = await panelcraft.getData();
await panelcraft.setData('scores', { home: 2, away: 1 });
panelcraft.subscribe(data => render(data));
await panelcraft.deleteData('scores');

    Spaces are isolated. Panel scripts cannot access other spaces, the parent page, or the network. The AI fetches external information with its own tools. Keep this local server running while using your dashboard.
